# AcxiomCRM - Enterprise Edition

A production-ready Customer Relationship Management (CRM) web application built with **ASP.NET Core 8.0**, **Entity Framework Core (SQLite)**, **Bootstrap 5**, and **ASP.NET Core Identity**.

---

## 🚀 Key Features

* **Authentication & RBAC:** Secure user login and Role-Based Access Control distinguishing between **Admins** and **Sales Representatives**.
* **Real-Time Dashboard:** High-level metrics tracking total customers, leads, active opportunities, and aggregated sales pipeline value.
* **Customer Management:** Comprehensive CRUD operations with search filtering and audit logging.
* **Lead Pipeline:** Capture and track prospective clients, lead sources, and estimated values.
* **Opportunity & Deal Tracking:** Monitor sales deals through various stages (Prospecting, Proposal, Negotiation, Closed-Won, Closed-Lost) with probability forecasting.
* **Activity & Follow-ups:** Schedule and track calls, meetings, emails, and tasks.
* **System Audit Logs:** Automated event logging tracking all critical create, update, and delete actions across the application (Admin-only access).

---

## 🛠️ Tech Stack

* **Framework:** ASP.NET Core 8.0 (MVC)
* **Database & ORM:** SQLite with Entity Framework Core (EF Core)
* **Security:** ASP.NET Core Identity with custom roles
* **UI / Styling:** Bootstrap 5, Bootstrap Icons, responsive layouts
